# 文档索引

本目录保存赛题说明、实验笔记和整理记录。代码和运行入口在项目根目录，提交结果在 `submission/`。

| 文件 | 内容 | 时效性 |
|---|---|---|
| `赛事概要.md` | 官方赛题：任务定义、数据规模、AUC 评分、提交格式 | 有效 |
| `资产与目录说明.md` | `output_*` 各目录、特征、模型、数据的用途、大小与活跃状态 | 2026-10-20 整理 |
| `旧特征40GB说明.md` | `output_v3`–`output_v6` 中约 40GB 旧 MFCC 特征的引用关系与删除影响 | 2026-08-06 记录，结论仍适用 |
| `history/` | 2026-08 前后的历史笔记：`PROGRESS.md`、`train_notes.md`、`improvement_loop_plan.md` | **历史快照**，结论可能已被推翻 |
| `整理记录_20261020.md` | 本次目录整理范围与检查结果 | 2026-10-20 |

## 建议阅读顺序

1. 根目录 `README.md`：当前最优、核心方法、关键结论。
2. `docs/赛事概要.md`：确认任务和提交格式。
3. `docs/资产与目录说明.md`：搞清楚哪个 `output_*` 是活跃的、哪些可以清理。
4. `submission/README.md`：保留的 5 个提交、已知分数与格式校验结果（其余 81 个已移到仓库外归档）。
5. `opt/README.md`：实验脚本地图；历史断点已移到 `history/PROGRESS.md`。

> `history/` 里的笔记保留的是当时的判断，部分结论后来被推翻（例如 500K 训练最终无效、ASR 路线失败）。引用前先看根 README 的“关键结论”。
