## 建议阅读顺序

1. 根目录 `README.md`：当前最优、核心方法、关键结论。
2. `docs/赛事概要.md`：确认任务和提交格式。
3. `docs/资产与目录说明.md`：搞清楚哪个 `output_*` 是活跃的、哪些可以清理。
4. `submission/README.md`：保留的 5 个提交、已知分数与格式校验结果（其余 81 个已移到仓库外归档）。
5. `opt/README.md`：实验脚本地图；`PROGRESS.md` 是 8 月 5 日的历史断点，不是最新状态。

> `improvement_loop_plan.md` 和 `train_notes.md` 保留的是当时的判断，部分结论后来被推翻（例如 500K 训练最终无效、ASR 路线失败）。引用前先看根 README 的“关键结论”。
