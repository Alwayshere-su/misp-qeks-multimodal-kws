# 资产与目录说明（2026-10-20）

本项目的目录名大量以 `output` 开头，容易混淆。下面按“最终链路是否依赖”分类。大小为 2026-10-20 实测（原始数据目录未逐文件统计）。

## 最终链路（保留）

| 路径 | 大小 | 作用 |
|---|---:|---|
| `output_whisper/` | 7.4 GB | 核心 whisper 特征：`val_feats.pkl`、`test_inset.pkl`、`test_outset.pkl`、`test_base_*.pkl`、`train_global/` |
| `output_p4/` | 48 MB | 最终监督模型：`best_full.pt`、`best_s2u.pt`、5 折权重、OOF 分数 |
| `opt/make_dtw_submit.py` | — | 生成最终最优提交 `submission/submit_gf_dtw.csv`（0.90042），基于已归档的 `submit_mt_gf_split.csv` |
| `opt/make_multitemplate_submit.py` | — | 生成 `submit_multitemplate.csv` 与 `submit_mt_full_w*.csv`；`submit_mt_gf_split.csv`（0.89995）的生成脚本未保留 |
| `opt/out_500k/best_500k.pt` | 5 MB | 500K 训练模型；实验用，最终多模板链路不依赖 |
| `scripts/` | 416 KB | 已按 analysis/asr/baseline/features/submission/tools 分类的脚本 |
| `submission/` | 11 MB | 5 个关键提交 CSV；其余 81 个在仓库外 `_archive_misp_submissions/`，说明见 `submission/README.md` |
| `docs/` | 36 KB | 文档 |
| `logs/` | 104 KB | 解压日志 |

## 旧特征与旧基线（已于 2026-10-20 删除）

| 路径 | 原大小 | 状态 |
|---|---:|---|
| `output_v3/` | 30 GB | v3 MFCC 帧级特征 + 权重；**已删除** |
| `output_v4/` | 2.9 GB | v4 文本+音频特征；**已删除** |
| `output_v5/` | 4.4 GB | v5 音频多模态特征；**已删除** |
| `output_v6/` | 2.9 GB | v6 视频特征；**已删除** |

`output_v3`–`output_v6` 合计 **40.2 GB**，经用户确认后删除，依据是 `docs/旧特征40GB说明.md` 的逐文件引用检查：最终提交与所有活跃实验都不依赖这些文件。代价是旧 baseline v3–v6 以及根目录 `train_matcher_v5.py`（输出到 `output_v5`）、`scripts/submission/make_submission.py`（读取 `output_v3`）无法直接重跑。

`output_lip/`（226 MB）未删除，保留作为视频实验记录。

## 官方数据与外部资源

| 路径 | 说明 |
|---|---|
| `train/` | 500K 训练集（wav/mp4/label/fa）；约 20 GB，官方数据，不可公开分发 |
| `test/` | Eval-Seen/Eval-Blind 各 50K 测试集与 enrollment 文本；约 4.3 GB |
| `val/` | 10K 开发集（dev_seen/dev_unseen） |
| `辅助资源/` | whisper-tiny、lipreading 预训练权重、噪声、SNR map；约 1.5 GB |
| `提交样例/` | 官方提交格式样例（约 1.6 MB） |

## 一句话结论

- **跑最终提交**：`output_whisper/` + `output_p4/` + `opt/make_dtw_submit.py`（基于归档的 `submit_mt_gf_split.csv`）。
- **看历史实验**：`output/`、`output_v2`、`output_v3e`、`output_lip`。
- **已清理**：`output_v3`–`output_v6` 共 40.2 GB 已于 2026-10-20 删除。
